01目标与原则

对齐原稿：提效、重构信息架构、降低误操作与认知负荷。

核心区优先

压缩非核心操作占比，把可视面积还给「人 × 日」排班矩阵与智能配置表。

任务分层

顶栏放全局能力（智能排班 / 自动），工具栏随 Tab 显隐，统计页只留表格。

规则外露

互斥、切换、删除等高风险动作必须二次确认；班次色系与 chip 尺寸固定可扫读。

02当前交互链路

原型入口：排班倒班模块 → 智能排班（向导 / 弹窗按场景分流）。

A. 常规排班（排班表）

Step 1查询部门 / 考勤组 / 月份
Step 2Tab：排班表｜排班统计
Step 3工具栏编辑班次人员；智能排班入口 + 自动开关
Step 4矩阵编辑 / 筛选 / 保存导出

B. 智能排班（国内向导）

Step 1确认班次与出勤：月度固定 / 周期轮换
Step 2加人校验（互斥切换确认）
Step 3调整并发布排班表
Step 4回写排班倒班主表

排班表 Tab

  • 展示操作工具栏、班次图例、排班矩阵
  • 顶栏：智能排班、自动、引导、导出
  • 次栏：临时修改 / 加人加班 / 密度 / 筛选保存

排班统计 Tab

  • 不展示排班表工具栏，避免假操作入口
  • 仅保留统计表格，降低信息噪声
  • Tab 去图标、间距 32、字号 14，对齐 LUI

03常规排班：原稿问题 → 方案

对应 PRD 4.1.1。目标是「看得见班表、找得到操作、认得出班次」。

原稿问题 落地方案 为什么这样做 / 解决什么
P0
非核心区占比高，核心矩阵被挤压，人多需横向猛滑 		双层工具栏收敛：全局能力上置，编辑操作次置；统计 Tab 隐藏编辑工具栏；矩阵区最大化 把视觉权重还给「人员 × 日期」。减少滚动与视线跳跃，提升扫读与改班效率。
P0
操作菜单多且分散，无区域划分、无说明 		左侧编辑动作、右侧视图/筛选/保存；新手引导与导出贴近「自动」；筛选浮层行距 16px 按「改数据 / 看数据 / 学规则」分区，降低找按钮成本，避免操作区持续抢焦点。
P1
排班统计独立感强，用途不匹配单独 sheet 体感 		保留同页 Tab，但不复用排班编辑工具；统计页只读表 统计与编辑任务目标不同。同入口切换，避免「看起来能改其实不该改」的误导。
P0
班次颜色混乱，难快速区分早/中/晚 		按班次族固定色板；图例 chip 定宽；时间单段展示，禁止超长双段撑宽 颜色承载语义而非装饰。固定尺寸保证矩阵对齐，降低「找色块」时间。
P1
操作指引与规则入口不明显 		顶栏固定「新手引导」；智能排班气泡提示；关键删除/切换二次确认 规则应「可被发现」。把帮助入口放到全局视线区，减少「不知道能不能点」。

04智能排班：原稿问题 → 方案

对应 PRD 4.2.1。核心矛盾是「推荐结果可改，但规则互斥且原路径过长」。

原稿问题 落地方案 为什么这样做 / 解决什么
P0
非核心操作区占比过高（约 50%） 		向导两步：①确认出勤（月度/周期）②调整发布班表；查询信息收束为只读条 智能排班是「确认推荐 → 微调 → 发布」。压缩装饰与旁路操作，保证决策面在表上。
P2
「月度固定 / 周期轮换」命名不够通俗 		原型保留业务正式名；通过 Tab + 表格结构差异强化语义（人班次表 vs 人时段表） 短期不靠改名解决认知，而靠「看见不同表结构就懂」。改名需业务共识，避免线上口径分裂。
P0
月度固定：未绑定班次也展示，满屏无用 00000 		仅展示已排人员的班次行；无人班次不渲染 空配置不是信息。去掉噪声列/行，缩短横向扫视路径，避免误把 0 当有效计划。
P0
一人只能一种方式，原路径需先删后加；无提示 		两侧均可选全员；若已在另一侧，二次确认后自动迁移 把「互斥规则」从隐式约束变成显式交互。缩短切换路径，防止双份排班冲突。
P1
周期轮换操作按钮过近，易误删 		复制 / 删除分区；删人二次确认；段内删除用垃圾桶并与下拉分离 降低误触成本。复制改为「套配置给其他人」，符合真实复用意图。
P0
周期分段固定 4 段，且只能从后往前删 		时段可任意增删；表头随段数扩展；一屏约 4 段，超出横滑；人员/操作列 sticky 满足「多段轮换」真实业务，同时保证单屏可读。随意删段避免被迫倒序维护。
P1
发布班表操作区偏弱 		第二步独立「调整并发布」；图例可收起；过去日期弱化、今日高亮 发布是终局动作，应有独立决策空间；弱化历史日降低干扰。

05关键取舍说明

方案选择的底层逻辑：优先「任务完成路径」与「错误成本」，其次才是视觉装饰。

做了什么

  • 信息架构分层：全局 / 编辑 / 只读统计
  • 智能排班互斥规则产品化（确认即切换）
  • 周期时段自由增删 + 横滑可读
  • 班次视觉：色板语义化、chip 定宽
  • LUI PC3.0：14 字号、16 间距、32 控件高

刻意没做什么

  • 未强行改「月度固定/周期轮换」业务命名
  • 未把统计能力硬塞进编辑工具栏
  • 未用更多弹层替代表格内联编辑
  • 历史数据迁移：原稿为「无」，本期不扩 scope

验收关注点（精简）

场景 预期
排班统计 Tab 无编辑工具栏，仅统计表
月度固定空班次 无人班次不出现，无 00000 噪声
月度 ↔ 周期加人 互斥确认后自动迁移并落表展示
周期 > 4 段 可横滑查看；可删任意段；可继续添加
